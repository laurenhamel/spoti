## Contributing

1. Clone the repository:
   ```sh
   git clone https://github.com/laurenhamel/spoti
   ```
2. Install dependencies:
   ```sh
   nvm use && yarn install
   ```
3. Create a global `npm` link:
   ```sh
   npm link
   ```
4. Happy hacking!
